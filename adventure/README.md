## Play
Main menu → ADVENTURE → select one of four existing free fighters → NEW VOYAGE / CONTINUE.
Joystick or A/D/arrow keys; Jump/Space/K (double jump), J attack, L block, O dash.
Pull joystick down or S/Down to drop through a one-way ledge. E or contextual button opens a nearby chest / challenges boss. Escape or pause button pauses. Android Back pauses/leaves; blur/portrait pauses and clears all input.
